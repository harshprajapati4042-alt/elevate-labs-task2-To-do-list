# elevate-labs-task2-To-do-list
To-Do List Web App

A simple and responsive To-Do list web app built with HTML, CSS and JavaScript. Users can add tasks, mark them complete, edit them and delete them. No page reload is needed.

This project is part of Task 2 of the Web Development Internship (Elevate Labs).

Features :
Add a new task using the Add task button or the Enter key
Mark a task as complete using the checkbox (the task gets a line through it)
Delete any task with the Delete button
Edit a task by double-clicking on it
Empty tasks are not added
Tasks are saved in the browser using localStorage, so they stay after a page refresh
UI updates instantly without reloading the page
Responsive design that works on mobile, tablet and desktop

Technologies Used :
HTML5 for the page structure
CSS3 for styling, layout (Flexbox) and responsive design
JavaScript (ES6) for DOM manipulation and event handling

Concepts Learned :
Selecting elements in the DOM (getElementById)
Creating and adding elements dynamically (createElement, appendChild)
Event listeners (click, change, keydown, dblclick)
Adding and removing classes with classList
Working with arrays (push, splice, forEach)
Saving data with localStorage
Responsive design with media queries
